Multi-view K-means algorithms make you pick the number of clusters c before they run. This post describes a three-stage scheme that estimates c by scoring a range of candidate partitions with clustering validity indices, while keeping the view and feature weights each algorithm has learned.

The problem

Multi-view clustering uses several feature sets of the same objects to find a better partition than any single view gives [1][2]. K-means-based methods are popular here because they are simple and scale linearly in the number of objects.

Four recent multi-view K-means algorithms add learned weights on views and on features: WMCFS [3], SWVF [4], TW-Co-K-means [5] and FRMVK [6]. All four take c as an input, and in practice c is rarely known.

Clustering validity indices (CVIs) estimate c by scoring the partitions obtained for a range of candidate values. The difficulty is that most CVIs assume one feature space and an unweighted distance. It is unclear how to apply them to partitions built under learned view and feature weights, and whether the individual views agree on c.

The paper contributes four things:

  • a three-stage scheme that selects c for the four algorithms;
  • a view- and feature-weighted distance that carries the learned weights into the Dunn index and classification entropy;
  • a single-view reference analysis with six further CVIs;
  • an evaluation protocol.

Four algorithms, one weighted distance

Take n objects observed in s views, with xih in ℝdh, c clusters, crisp memberships μik, cluster centers akh, view weights vh that sum to 1, and feature weights wjh that sum to 1 within each view.

  • WMCFSOne global partition through weighted distances.
  • SWVFOne global partition through weighted distances.
  • FRMVKOne global partition through weighted distances.
  • TW-Co-K-meansA membership matrix per view, plus a collaboration term that penalizes disagreement between views. Its global partition is the merged matrix Ū = Σh vh Uh.

Each algorithm weights the squared distance between an object and a center with a view factor V and a feature factor Wh. Table 1 lists them. The full objectives and update equations are in the original papers.

Eight validity indices

Eight CVIs are considered, each evaluated for c = 2, …, cmax. Table 2 gives the rule each one uses to pick the best c.

One practical catch: crisp K-means memberships give PC = 1 and CE = 0 for every c, so these two indices only work with soft memberships. The scheme below computes pseudo-memberships for that reason.

The three-stage scheme

  1. Candidate range

    Fix c = 2, …, cmax and the algorithm parameters.

  2. Partition

    For each c, run the multi-view K-means algorithm from several random starts and keep the run with the lowest objective value.

  3. Selection

    Compute the CVI from the kept partition and its learned weights, then choose c by the rule of the index.

The weighted distance

The Dunn index and classification entropy are embedded in the four algorithms through one distance that uses the factors from Table 1:

Dunn index and classification entropy

The Dunn index uses ρ between objects. For classification entropy, pseudo-memberships are computed from the same distance. They are used for scoring only, with fuzzifier m = 2:

\[ u_{ik}=\frac{[\rho^{2}(x_i,a_k)]^{-1/(m-1)}}{\sum_{\ell=1}^{c}[\rho^{2}(x_i,a_\ell)]^{-1/(m-1)}} \]
\[ \mathrm{CE}(c)=-\frac{1}{n}\sum_{i=1}^{n}\sum_{k=1}^{c}u_{ik}\ln u_{ik} \]

A single-view reference

The other six indices are applied to K-means on each view separately. That gives a selected c*h per view. Comparing them shows whether the views agree on c and how the multi-view choice sits against them.

Planned evaluation

None of this has been run. The protocol is fixed here so the study can be reproduced, and labels are used only for assessment, never for selecting c.

  • Synthetic dataTwo multi-view Gaussian data sets, each replicated 30 times. Example 1: n = 300, 3 views, c = 3, with views of different clarity. Example 2: n = 500, 4 views, c = 5, with overlapping clusters and one pure-noise view.
  • Real dataCandidates are Handwritten digits (UCI Multiple Features), 3Sources, BBCSport and Caltech101-7. Each has a known number of classes that serves as ctrue.
  • Settingsc = 2, …, min(⌊√n⌋, 15); 20 random starts per c; algorithm parameters over the grids recommended in the original papers; gap statistic with B = 50 reference sets.
  • MeasuresRecovery rate of ctrue, mean absolute error of c, adjusted Rand index and normalized mutual information at the selected c, view consistency (the share of views whose c*h equals the multi-view c*), and run time.
  • ReportingThe most frequent c* over the parameter grid and its share, so that sensitivity to parameters is visible.

Limitations

Because no experiments have been run, the accuracy of the scheme is not yet established. Known limitations:

  • PC and CE favour small c and need pseudo-memberships.
  • The Dunn index is sensitive to extreme pairs and costs O(n2D), where D = Σh dh.
  • The selected c depends on the algorithm parameters.

Next steps are to run the protocol above, report the results, and extend the weighted indices to fuzzy multi-view clustering.
