1. Intuition: parts-based representation

Nonnegative matrix factorization (NMF) approximates a nonnegative data matrix using two smaller nonnegative matrices.

Given data \(X\), NMF seeks a low-rank approximation \(X\approx WH\). The columns of \(W\) are often called basis vectors or components; each column of \(H\) contains the weights used to reconstruct one observation. Because the factors are nonnegative, components combine additively rather than canceling one another.

Why nonnegative? In applications such as image intensities, counts, and document-term frequencies, negative values may be meaningless. Nonnegativity can also encourage interpretable, parts-based representations—but it does not guarantee unique or semantically meaningful components.

Typical applications include document analysis, image representation, exploratory analysis of spectra, and feature extraction. NMF is unsupervised: it does not use class labels during factorization.

2. Notation and dimensions

Let \(X\in\mathbb{R}_{\ge0}^{d\times n}\) contain \(n\) observations, each represented by \(d\) features. We choose a factorization rank \(r\), usually smaller than both \(d\) and \(n\):

$$X\approx WH,\qquad W\in\mathbb{R}_{\ge0}^{d\times r},\quad H\in\mathbb{R}_{\ge0}^{r\times n}.$$
SymbolShapeInterpretation
\(X\)\(d\times n\)Observed data (features × samples)
\(W\)\(d\times r\)Basis/components
\(H\)\(r\times n\)Component weights for each sample
\(r\)scalarChosen latent rank / number of components

We use uppercase bold letters for matrices, \((A)_{ij}\) for an entry, \(A^T\) for transpose, \(\operatorname{Tr}(A)\) for trace, and \(\|A\|_F\) for the Frobenius norm.

3. The least-squares objective

A common NMF formulation minimizes squared reconstruction error subject to nonnegativity:

$$\min_{W,H\ge0} f(W,H)=\frac12\|X-WH\|_F^2.$$

The factor \(\tfrac12\) is convenient because it cancels the factor 2 in derivatives. Equivalently, one may omit it without changing the minimizers.

Using \(\|A\|_F^2=\operatorname{Tr}(A^TA)\) and trace cyclicity, expand:

$$f(W,H)=\frac12\operatorname{Tr}(X^TX)-\operatorname{Tr}(X^TWH)+\frac12\operatorname{Tr}(H^TW^TWH).$$

The problem is jointly non-convex in \((W,H)\), although it is convex in either factor when the other is fixed. This motivates alternating optimization: update one factor while holding the other fixed.

Show the trace expansion
$$\begin{aligned} \|X-WH\|_F^2&=\operatorname{Tr}((X-WH)^T(X-WH))\\ &=\operatorname{Tr}(X^TX)-\operatorname{Tr}(X^TWH)\\ &\quad-\operatorname{Tr}(H^TW^TX)+\operatorname{Tr}(H^TW^TWH). \end{aligned}$$ By trace cyclicity, the two middle terms are equal scalars. Multiplying the whole expression by \(\frac12\) gives the objective above.

4. Deriving the gradients

For \(f(W,H)=\tfrac12\|X-WH\|_F^2\), the matrix gradients are:

$$\boxed{\nabla_W f=WHH^T-XH^T}$$
$$\boxed{\nabla_H f=W^TWH-W^TX}$$

These expressions have the same shape as the variable being differentiated: \(d\times r\) for \(\nabla_W f\), and \(r\times n\) for \(\nabla_H f\).

Show the gradient calculation

Write the objective in trace form and differentiate with standard matrix-calculus identities:

$$\begin{aligned} \nabla_W f&=-XH^T+WHH^T,\\ \nabla_H f&=-W^TX+W^TWH. \end{aligned}$$

For example, the derivative of \(-\operatorname{Tr}(X^TWH)\) with respect to \(W\) is \(-XH^T\), while that of \(\tfrac12\operatorname{Tr}(H^TW^TWH)\) is \(WHH^T\).

Constraint reminder. Ordinary gradient descent does not preserve \(W,H\ge0\). A constrained method or a positivity-preserving update is needed.

5. Multiplicative updates

A classic NMF algorithm uses elementwise multiplicative updates:

$$\boxed{W\leftarrow W\odot\frac{XH^T}{WHH^T+\varepsilon}}$$
$$\boxed{H\leftarrow H\odot\frac{W^TX}{W^TWH+\varepsilon}}$$

Here \(\odot\) and the fraction denote elementwise multiplication and division, respectively; \(\varepsilon>0\) is a small numerical safeguard. Initialize both factors with nonnegative values, and alternate the updates.

Algorithm sketch

Initialize W ≥ 0 and H ≥ 0
repeat until convergence:
    W ← W ⊙ (X Hᵀ) / (W H Hᵀ + ε)
    H ← H ⊙ (Wᵀ X) / (Wᵀ W H + ε)
return W, H

Under the standard assumptions and exact update formulation, these multiplicative rules are associated with non-increasing reconstruction error. In floating-point implementations, monitor the objective and use safeguards; convergence to a global optimum is not guaranteed.

6. Practical notes for students

Choose rank \(r\)Use domain knowledge, validation, or stability checks; rank is a modeling choice.
Scale thoughtfullyFeature scaling changes the geometry and may change the components.
Run multiple startsNMF can converge to different local solutions.
Inspect residualsTrack \(\|X-WH\|_F\), not just whether the code runs.

Least-squares NMF can be sensitive to large entries and outliers because squared residuals penalize large deviations strongly. Alternatives include divergence-based objectives or robust loss functions, depending on the data and assumptions.

7. Takeaways

  • NMF represents nonnegative data as a sum of nonnegative latent components.
  • The rank \(r\) controls the size of the representation.
  • The least-squares objective yields simple matrix gradients.
  • Multiplicative updates preserve nonnegativity for nonnegative initialization (with suitable numerical handling).
  • NMF is non-convex; interpretability and solution quality require validation.
